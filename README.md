# crudfinalphp

## Descrição

Este é um website desenvolvido em PHP que permite aos usuários realizar operações de CRUD (Criar, Ler, Atualizar e Deletar) em Clientes e Produtos.

## Funcionalidades

1. **Clientes**
    - Criar: Adicione novos clientes ao sistema.
    - Ler: Visualize a lista de todos os clientes.
    - Atualizar: Edite as informações dos clientes existentes.
    - Deletar: Remova clientes do sistema.

2. **Produtos**
    - Criar: Adicione novos produtos ao sistema.
    - Ler: Visualize a lista de todos os produtos.
    - Atualizar: Edite as informações dos produtos existentes.
    - Deletar: Remova produtos do sistema.

## Como usar

1. Clone este repositório para a sua máquina local.
2. Navegue até a pasta do projeto no seu terminal.
3. Execute o servidor PHP localmente.
4. Abra o seu navegador e acesse o endereço do servidor local.
